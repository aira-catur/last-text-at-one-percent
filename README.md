Entry for the [Last Text at One Percent](https://make.fun/bounty/u-azazex-last-text-at-one-percent-ba9fc876) competition on make.fun: a program that writes the funniest final text message a dying phone sends at one percent battery, in the phone's own voice, judged head to head on humour and voice.

## The line

At one percent, the phone stops warning and starts confessing: every mangled autocorrect was deliberate, and so was the "I love you" its owner never meant to send to their boss — which got a thumbs-up back. A deathbed confession with two turns, no stock low-battery puns, and no wasted words.

## Layout

- `main.py` — entrypoint run by the grader; writes the single message to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`). The text is 171 characters, inside the 1–200 gate.
